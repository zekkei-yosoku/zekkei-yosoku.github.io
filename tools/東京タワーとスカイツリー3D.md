# 無料2塔の自作3D（2026-10-07）

有料モデル・無料再投稿の第三者メッシュは使用していない。`build-free-towers.py`を実行すると、独立に作成した形状データ `sorami-tower-models.js` を再生成する。データは東・北・上のメートル座標。各faces要素は独立した凸部材であり、建物全体の凸包ではない。描画と接触判定は同じ投影部材の和集合を使う。

| パラメータ | 根拠 | 限界 |
| --- | --- | --- |
| 東京タワー333m、メイン150m、トップ250m | [公式施設案内](https://www.tokyotower.co.jp/guidance/)・[英語公式チケット](https://ticket.tokyotower.co.jp/en/) | 展望フロアの高さ。屋根/底の寸法とは区別 |
| スカイツリー634m、デッキ350m、回廊450m | [公式フロア](https://www.tokyo-skytree.jp/floor/) | 同上 |
| スカイツリー基部の一辺68m | [設計者 日建設計Journal2012秋](https://www.nikken.co.jp/ja/about/p4iusj0000001hyd-att/Journal-2012_Autumn.pdf) | 三角形から円への変化量は補間による推定 |
| 地理的方向、外形の参考 | PLATEAU港区・墨田区2025の対象Building LOD2を確認 | 原メッシュを採用したモデルではない。測量精度の保証なし |
| 部材太さ/数/間隔、曲線、デッキの外形、付属設備 | 自作の推定 | 実際の鋼管配置/BIM/全装備の再現ではない |

画面と共有画像に「自作3D・格子と形状は推定」を表示する。遠景の見え方の目安に使う。特定の鋼管への厳密な重なりを予測する精度はない。近距離の撮影や格子の微細な隙間では現地写真による追加校正が必要。

PLATEAU対象Building: 東京タワー `bldg_7aff4a51-be8b-405b-abe4-ac489697cbc8`、スカイツリー `bldg_58ab8c46-8369-49c4-86cf-6912bbc4efe1`。[港区2025](https://www.geospatial.jp/ckan/dataset/plateau-13103-minato-ku-2025)、[墨田区2025](https://www.geospatial.jp/ckan/dataset/plateau-13107-sumida-ku-2025)、[PLATEAU利用条件](https://www.mlit.go.jp/plateau/site-policy/)。基部の商業施設を目標全体の判定に混ぜない。

先の東京タワー125m/224mは公式案内と矛盾する設定だった。目標部位と観測地点の展望台一覧を150m/250mに訂正した。保存済みお気に入りで旧部位を選択していた場合はfreshDecksが同じ部位番号の公式値へ更新する。明示的に共有されたプランの高さは従来通り送信者の選択を保持する。

検証: `node --test test-free-towers.mjs` で方位差、地上高/標高の区別、鉄骨の内部と隙間の判定、縦の高さ編集、日別計算時間、既存城/都庁の存続を確認する。
