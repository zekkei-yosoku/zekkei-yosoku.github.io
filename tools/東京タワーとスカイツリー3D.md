# 無料2塔の図面参照3D（2026-10-08・現行）

現在の根拠・精度・独立レビューは[全モデルの精度監査](全モデルの精度監査.md)を優先する。第三者の有料/再投稿メッシュは使用せず、build-free-towers.pyから自作の近似形状を生成する。

東京タワーは図面の80m正方形脚/傾斜脚内のアーチ/展望台外形を反映。部位は床の公称値ではなく物理的な上端を狙う。スカイツリーは基部68m正三角形/315mの直径32m円/そりむくりを設計説明で拘束。細部の鉄骨や方位は推定。

座標は東・北・上のメートル。facesの各要素は凸な部材の頂点群であり、modelOutlineで部材ごとに投影凸包を取る。描画と接触判定は同じ部材の和集合。隙間を建物全体の凸包で埋めない。画面と共有画像に「図面参照3D・細部は推定」を表示する。

生成：python3 tools/build-free-towers.py。回帰：node --test test-free-towers.mjs。保存済みの展望台選択はfreshDecksで床高を更新し、独自の高さ・地面に立つ選択・共有URLの明示条件は保持。
