# 絶景予測

自然現象の見え方と撮影日時を調べるWebアプリです。
公開先: [絶景予測](https://zekkei-yosoku.github.io/)

## 構成

- `index.html` — 画面と道具間の連携
- `sorami-prediction.js` — 非公開予測APIの取得・条件照合・キャッシュ
- `sorami-core.js` — 表示、暦、気象データの標準的な扱い
- `sorami-astro.js` / `sorami-aim.js` — 天文計算、目標への幾何と見え方
- `sorami-sky-map.js` — 地図上の天体の方位・高度と出入り
- `sorami-datetime-ui.js` — 重ねるとスカイマップで共有する日時操作
- `sorami-platform.js` / `platform.css` — AstroNotes・絶景予測の切替、共通の地点・日時、連携、下部ナビゲーション

上部の `AstroNotes｜絶景予測` は同じWebアプリ内の切替です。ログイン・利用権限・お気に入り・観測記録は既存基盤を共用します。観測・撮影計画はブラウザ内のアカウント別保存で、サーバー同期はありません。共通日時は内部ではUTCの瞬間を保持し、現行の天体ツールに合わせ日本時間で表示します。海外の現地時間への全面対応を意味するものではありません。

共通条件や戻り先にはアカウント境界を設け、権限確認待ちの古い結果を別利用者へ適用しません。地点を変更した場合、取得条件が一致するまで前の地点の予測値を表示しません。天文計算・予測式・既存API/DBの構造は維持しています。

独自の採点処理・学習係数・研究用コードは非公開APIリポジトリで管理します。
過去に公開済みの版や、画面に表示する予測結果まで非公開にできるものではありません。
一般的な天文計算と地図の操作は端末で処理します。

## 確認

各 `test-*.mjs` をNode.jsで実行します。HTML変更後は
`node update-csp.mjs` でインラインスクリプトのCSPハッシュを更新します。
配信後は通常URLのファイル内容と、地図・日時・権限の実画面も確認します。

Playwrightが使える環境では、ローカルHTTPサーバーを起動し `node tools/test-platform-browser.cjs http://127.0.0.1:8795/` で切替・共通条件・計画・アカウント隔離・権限取消・320/390/1280pxを確認できます。Playwrightを別の場所に用意した場合は `PLAYWRIGHT_MODULE` にモジュールのパスを指定します。APIはテスト内のダミー応答に置き換え、実アカウントや本番データを書き換えません。`PLATFORM_TEST_OUTPUT` で検証結果の保存先を指定できます。

## 出典

気象: Open-Meteo、気象庁。地図: OpenStreetMap、国土地理院。
光害: Lorenz Light Pollution Atlas 2025。建物形状の資料と使用条件は画面の出典および `tools/` に記載しています。
